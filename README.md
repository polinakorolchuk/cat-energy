# Верстка макета Cat Energy

## Описание проекта

Данный проект представляет собой адаптивную, кросс-браузерную вёрстку лендинга по макету из Figma. Вёрстка выполнена вручную, без использования внешних CSS/JS библиотек с применением SCSS для упрощения работы со стилями.

Результат — готовые файлы index.html, styles.css, script.js, а также удалённый git-репозиторий с коммитами и README. 
Проект задеплоен на GitHub Pages - https://polinakorolchuk.github.io/cat-energy/

Макет доступен по ссылке: [Figma Design](https://www.figma.com/design/gqM9B9ZUTgcmVXsQ2W7V8C/%D0%9A%D1%8D%D1%82%D1%8D%D0%BD%D0%B5%D1%80%D0%B4%D0%B6%D0%B8---landing-Copy-?node-id=2403-436&t=MrcbOXLIoeKLMGxM-0)

## Технологии и инструменты

- **HTML5** — семантическая структура страниц
- **CSS3 / SCSS** — стилизация и адаптивность
- **JavaScript** — интерактивный слайдер "Живой пример"
- **Yandex.Map API** — подключение карты
- **Git / GitHub** — контроль версий и деплой

## Особенности реализации

- **Адаптивность:** корректное отображение на мобильных, планшетных и десктопных устройствах.
- **Интерактивность:** слайдер "Живой пример" с эффектом сравнения изображений котов.
- **Стилизация:** использование SCSS переменных для цветов и упрощения поддержки стилей.
- **Семантика:** корректная структура блоков и использование валидных HTML-тегов.
- **Кросс-браузерность:** протестировано в последних версиях популярных браузеров.
